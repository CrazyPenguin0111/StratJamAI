Follow a game on the original site

  1. Keep this site available while you play. Visitors to a public site do not need to run their own server.
  2. Install a browser userscript manager, then install the Enclosure live coach script.
  3. Open or reload the original Enclosure site. In its new “StratJamAI coach” panel, enter this server's address: the address in this page's browser address bar.
  4. Click Connect coach and allow its popup. Keep the popup open. The panel will display a suggested line after each placement; the popup shows the reconstructed board and search.

Play moves in the original tab. The coach observes both players and refreshes automatically, including practice undo, redo, and reset. It suggests moves; it does not submit them. Adjust thinking time in the popup.

The connection uses a separate game session, so your ordinary game here is preserved. Only game positions and moves are copied; account details and chat are not sent.

Practice games can be connected midway. Online games need a complete move history; connect before the first placement if the site does not supply one. If the replay differs from the site's position, suggestions stop instead of using an incorrect board. This adapter depends on the current site's React state layout and may need updating if the site changes.
